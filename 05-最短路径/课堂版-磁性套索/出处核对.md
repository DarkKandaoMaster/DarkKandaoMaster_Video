## 1. Intelligent Scissors（Mortensen & Barrett, SIGGRAPH 1995）

**结论：成立。可信度：高**（论文原文 + ACM SIGGRAPH 官方档案）

- 标题 / 作者 / 会议 / 年份：*Intelligent Scissors for Image Composition*，Eric N. Mortensen、William A. Barrett（Brigham Young University，杨百翰大学），SIGGRAPH 1995 Technical Papers。
- 算法：把像素当节点，每个像素和 8 个邻居连边，求起点到终点"累计代价最小"的路径；论文明说用的是"和 Dijkstra 提出的类似"的最优图搜索（论文自己把它叫 2-D dynamic programming / graph search，参考文献 [6] 就是 Dijkstra 1959）。
- 局部代价由三项加权组成：**Laplacian 过零（fZ）+ 梯度幅值（fG）+ 梯度方向（fD）**，经验权重 ωZ = 0.43、ωD = 0.43、ωG = 0.14。梯度幅值项做了"取反"（fG = 1 − G/max(G)），所以边缘越强，代价越低，路径就贴着边缘走。梯度方向项负责惩罚"急转弯"，让边界更平滑。

**原文摘录**

> "the graph search consists of finding the globally optimal path from a start pixel to a goal pixel--in particular, pixels represent nodes and edges are created between each pixel and its 8 neighbors. For this paper, optimality is defined as the minimum cumulative cost path from a start pixel to a goal pixel where the cumulative cost of a path is the sum of the local edge (or link) costs on the path."（第 3 节）

> "This paper utilizes an optimal graph search similar to that presented by Dijkstra [6] and extended by Nilsson [13]"（3.2 节）

> "l(p,q) = ωZ·fZ(q) + ωD·fD(p,q) + ωG·fG(q) … (Empirically, weights of ωZ = 0.43, ωD = 0.43, and ωG = 0.14 seem to work well in a wide range of images.)"（3.1 节；表头三项为 "Laplacian Zero-Crossing / Gradient Magnitude / Gradient Direction"）

> "The gradient direction adds a smoothness constraint to the boundary by associating a high cost for sharp changes in boundary direction."

> ACM SIGGRAPH 档案页："Intelligent scissors for image composition / SIGGRAPH 1995 / Presenters / Authors: Eric N. Mortensen, William A. Barrett … SIGGRAPH 1995: Technical Papers"；摘要："When the gestured mouse position comes in proximity to an object edge, a live-wire boundary "snaps" to, and wraps around the object of interest."

**链接**

- 论文 PDF（华盛顿大学课程阅读材料；原链接现在要登录，读的是 Wayback 存档）：https://web.archive.org/web/20240731132312/https://courses.cs.washington.edu/courses/cse576/03sp/readings/mort-sigg95.pdf （本地副本 `开发\出处截图\pdf\mort-sigg95.pdf`，第 2 页渲染 `page_mort-sigg95-2.png`）
- ACM SIGGRAPH 历史档案：https://history.siggraph.org/learning/intelligent-scissors-for-image-composition-by-mortensen-and-barrett/
- 页码 191–198 只在搜索摘要（dblp）里见过，dblp 页面被人机验证挡住、没打开，**录课里不要报页码**。

**课上建议说法**

> "1995 年有两位研究者做了个'智能剪刀'：把图片的每个像素看成图的一个顶点，相邻像素连边，越像物体边缘的地方边越'便宜'。你点两个点，电脑用和 Dijkstra 一样思路的最短路径算法，找出两点之间'最便宜'的路，这条路自然就贴着物体边缘走。"

## 2. Photoshop 磁性套索是否基于 Intelligent Scissors / 最短路径

**结论：部分成立。可信度：中。**

- **有一手说法，但来自发明者一方，不是 Adobe**：杨百翰大学（BYU）官方新闻（2006-07-24）和校刊 *Y Magazine* 都写了：Barrett 的 Intelligent Scissors "改名为 magnetic lasso，从 Photoshop 5.0 起被集成进去"。这是发明者所在大学的说法，算一手，但不是 Adobe 自己说的。两篇都出自 BYU，只算**一组**独立来源；ScienceDaily 那篇是同一新闻稿的转载，不另算。
- **学术界旁证**：微软亚洲研究院等人的 *Lazy Snapping*（SIGGRAPH 2004）称 Photoshop 的磁性套索"大概是 intelligent scissor 最好的实现"。这是同行对外观和行为的判断，不是看过 Adobe 代码得出的。
- **Adobe 官方帮助文档只讲行为、不讲算法**：只说"选区会吸附到图像里最强的边缘"，设置项有 Width / Contrast / Frequency，**没有提** Intelligent Scissors、live-wire、最短路径或 Dijkstra。本次检索也没找到 Adobe 自己公开说过算法原理（查过 Adobe 帮助页和"Adobe patent magnetic lasso"一类关键词，没有结果）。
- 所以："磁性套索源自 Intelligent Scissors"有中等强度的证据（发明者大学 + 同行论文）；"现在的 Photoshop 内部用的就是 Dijkstra"**没有公开证据**，不能这么说。

## 3. OpenCV 里的 Intelligent Scissors 实现

**结论：成立。可信度：高**（OpenCV 官方文档 + 官方发布说明）

- 类名 `cv::segmentation::IntelligentScissorsMB`，头文件 `opencv2/imgproc/segmentation.hpp`，文档归在 **imgproc 模块**的"Image Processing » Image Segmentation"下。Python 里叫 `cv.segmentation.IntelligentScissorsMB()`。
- 版本：OpenCV **4.5.2**（2021-04-06 发布）的 Release highlights 写了"Added IntelligentScissors algorithm implementation"；4.5.2 的文档里已经有这个类页面，同一路径在 4.5.1 文档里是 404（弱旁证：Doxygen 路径可能变，不能单靠它）。到 4.13.0 文档仍在。
- 文档描述：用来找两点之间的路径（轮廓），可以用于图像分割；参考文献就是 Mortensen & Barrett 那篇。主要接口：`applyImage`（提取特征）→ `buildMap(sourcePt)`（为起点算"最优路径图"）→ `getContour(targetPt)`（取到终点的最优轮廓）。可以切换 Canny 或 "Laplacian Zero-Crossing" 两种边缘特征，`setWeights` 设三项权重。
- 补充：OpenCV 官方示例 `samples/cpp/intelligent_scissors.cpp` 里的 `find_min_path` 用 `std::priority_queue`（优先队列）加代价表逐点扩展，就是 Dijkstra 的写法，局部代价权重也是 0.43 / 0.43 / 0.14。类文档本身没写 "Dijkstra" 这个词。

**原文摘录**

> OpenCV 4.13.0 类文档："Intelligent Scissors image segmentation. This class is used to find the path (contour) between two points which can be used for image segmentation. … Reference: "Intelligent Scissors for Image Composition" algorithm designed by Eric N. Mortensen and William A. Barrett, Brigham Young University"

> "#include <opencv2/imgproc/segmentation.hpp>"；"buildMap … Prepares a map of optimal paths for the given source point on the image."；"getContour … Extracts optimal contour for the given target point on the image."；"setEdgeFeatureZeroCrossingParameters … Switch to "Laplacian Zero-Crossing" edge feature extractor"

> OpenCV 4.5.2 发布页（2021-04-06）："Release highlights … Added IntelligentScissors algorithm implementation"

## 4. Felzenszwalb & Huttenlocher, IJCV 2004 "Efficient Graph-Based Image Segmentation"

**结论：成立。可信度：高**（作者主页上的论文原文 + scikit-image 官方文档）

- 出处：*International Journal of Computer Vision*, Vol. 59, No. 2, September 2004（作者主页写明）。
- 算法第 0 步就是"把边按权重从小到大排序"，然后每个像素自成一个区域，依次看每条边，满足条件才把两端所在区域合并。论文自己说这个算法和 Kruskal 求最小生成树"密切相关"，实际触发合并的边"正是 Kruskal 会选的边"。
- 实现用的是**并查集（disjoint-set forest），带按秩合并和路径压缩**，总时间 O(m log m)。
- 和 Kruskal 的区别：Kruskal 只要两端不在同一集合就合并；这里还多一个判断（边权要小于两个区域各自的"内部差异 + 阈值"），不满足就不合并，所以最后得到的是一片"森林"（多个区域），而不是一棵树。
- scikit-image 有 `skimage.segmentation.felzenszwalb(image, scale=1, sigma=0.8, min_size=20, *, channel_axis=-1)`（查的是 0.26.0 文档）。文档把它描述成"基于最小生成树的快速聚类"。注意文档里把人名错拼成 "Felsenszwalb"，PPT 上别照抄。

**原文摘录**

> "We now turn to the segmentation algorithm, which is closely related to Kruskal's algorithm for constructing a minimum spanning tree of a graph (cf. [6]). It can be implemented to run in O(m log m) time, where m is the number of edges in the graph."

> "0. Sort E into π = (o1, . . . , om), by non-decreasing edge weight. 1. Start with a segmentation S0, where each vertex vi is in its own component. … If vi and vj are in disjoint components of Sq-1 and w(oq) is small compared to the internal difference of both those components, then merge the two components otherwise do nothing."

> "Thus the edges causing merges are exactly the edges that would be selected by Kruskal's algorithm for constructing the minimum spanning tree (MST) of each component."

> "Our implementation maintains the segmentation S using a disjoint-set forest with union by rank and path compression (cf. [6])."

> "As with certain classical clustering methods [15, 19], our method is based on selecting edges from a graph, where each pixel corresponds to a node in the graph, and certain neighboring pixels are connected by undirected edges. Weights on each edge measure the dissimilarity between pixels."

> scikit-image 文档："skimage.segmentation.felzenszwalb(image, scale=1, sigma=0.8, min_size=20, *, channel_axis=-1) Computes Felsenszwalb's efficient graph based image segmentation. Produces an oversegmentation of a multichannel (i.e. RGB) image using a fast, minimum spanning tree based clustering on the image grid."

**链接**

- 作者主页（写明 IJCV 59(2), 2004 + 代码）：https://cs.brown.edu/people/pfelzens/segment/index.html
- 论文 PDF（作者主页链接）：https://cs.brown.edu/people/pfelzens/papers/seg-ijcv.pdf （本地 `pdf\seg-ijcv.pdf`，第 10、13 页渲染 `page_seg-ijcv-10.png`、`page_seg-ijcv-13.png`）
- scikit-image 文档：https://scikit-image.org/docs/stable/api/skimage.segmentation.html （截图 `shots\S18.png`）

**课上建议说法**

> "还有一种自动把图片切成一块块的经典方法（2004 年）：把相邻像素之间的颜色差当边权，从最小的边开始，一条条看要不要把两块合并。这和我们学的 Kruskal 求最小生成树几乎是一个套路，判断'在不在同一块'用的也正是并查集。"

## 5. 魔棒 / flood fill 本质是在像素网格图上做 BFS / DFS 求连通区域

**结论：flood fill 成立（高可信）；"魔棒"部分成立（中可信）。**

- **普林斯顿 Sedgewick & Wayne《Algorithms》课件**（COS 226，2010，"4.1 Undirected Graphs"）直接把 Photoshop "magic wand" 当作 flood fill 的例子：建网格图，像素是顶点，相邻同色像素之间连边，要找的是和给定像素连通的那一整块（blob）。它放在深度优先搜索（DFS）一节，作为"连通性应用"讲。这是权威教材作者的课件，可以引用。
- **OpenCV 官方文档**：`floodFill` 就是"用给定颜色填充一个连通分量"，连通与否看相邻像素的颜色 / 亮度是否接近。
- **维基百科（三手资料，只作辅助）**：flood fill 可以用递归（隐式栈），也可以显式用栈或队列；"用栈就是深度优先，用队列就是广度优先"。
- **Adobe 魔棒官方帮助**：只有勾选 "Contiguous（连续）" 时才"只选相邻的相近颜色区域"；不勾选时会选中整张图里所有颜色相近的像素，那就不是求连通区域了。Adobe 没公开魔棒的内部实现，实际软件多用扫描线填充之类的优化写法，未必是教科书式的逐像素 BFS / DFS。
- 所以："flood fill 求的是像素网格图上的连通区域，可以用 BFS 或 DFS 实现"是教材级结论；"魔棒（勾选'连续'时）做的就是这件事"有普林斯顿课件撑腰；"Photoshop 内部用的就是 BFS"查不到。

**原文摘录**

> 普林斯顿课件（Algorithms in Java 4th Ed. © Robert Sedgewick and Kevin Wayne，2010 年 3 月版）第 33–36 张："Flood fill — Photoshop "magic wand"" ；"Connectivity application: flood fill. Change color of entire blob of neighboring red pixels to blue. Build a grid graph. • Vertex: pixel. • Edge: between two adjacent red pixels. • Blob: all pixels connected to given pixel."

> OpenCV 文档："Fills a connected component with the given color. The function cv::floodFill fills a connected component starting from the seed point with the specified color. The connectivity is determined by the color/brightness closeness of the neighbor pixels."

> Wikipedia "Flood fill"："Moving the recursion into a data structure (either a stack or a queue) prevents a stack overflow. … it pushes the nodes onto a stack or queue for consumption, with the choice of data structure affecting the proliferation pattern"；"Using a stack explores spans depth first, whilst a queue explores spans breadth first."

> Adobe 魔棒帮助（最后更新 2026-02-23）："Contiguous: Enable to select only adjacent areas of similar color."

**链接**

- 普林斯顿课件 PDF：https://www.cs.princeton.edu/courses/archive/spr10/cos226/lectures/12-41UndirectedGraphs-2x2.pdf （第 9 页渲染 `pdf\page_princeton-undirected-spr10-09.png`，上面就是这四张幻灯片）
- OpenCV floodFill：https://docs.opencv.org/4.13.0/d7/d1b/group__imgproc__misc.html
- Wikipedia：https://en.wikipedia.org/wiki/Flood_fill
- Adobe 魔棒：https://helpx.adobe.com/photoshop/desktop/make-selections/automatic-color-based-selections/select-areas-by-color-with-the-magic-wand-tool.html （截图 `shots\S21b.png`）
- 附带看过 algs4 网站 4.1 节（https://algs4.cs.princeton.edu/41graph/ ），里面讲了 DFS 求连通分量，但**网页版没有 flood fill 字样**，所以 flood fill 引的是课件而不是网站。

**课上建议说法**

> "PS 里的魔棒（勾选'连续'时），点一下就选中一整片颜色相近的区域。换成图的语言：每个像素是一个顶点，相邻且颜色相近的像素之间连一条边，魔棒要找的就是你点的那个像素所在的连通块。这正是 BFS 或 DFS 能做的事，普林斯顿的算法课就拿它当例题。"

## 6. 关键点 / 骨架建成图、写成邻接矩阵，送进图卷积网络

**结论：人体骨架成立（高）；人脸关键点部分成立（高可信，但要改一个细节）。**

### 6a. ST-GCN（Yan, Xiong, Lin, AAAI 2018）——人体骨架

- 关节当顶点；同一帧里按人体天然连接（骨头）连边，相邻帧的同一关节也连边（时间边）。
- 一帧之内的连接用**邻接矩阵 A** 表示，再加单位矩阵 I 表示自环，按 Kipf & Welling 的方式归一化：f_out = Λ^(-1/2) (A + I) Λ^(-1/2) f_in W，其中 Λ^ii = Σ_j (A^ij + I^ij)（式 9，就是度矩阵）。
- 另外还给每层的邻接矩阵乘了一个可学习的权重掩码 M（"(A + I) ⊗ M"），让每条边的重要性也能学。
- 发表信息：AAAI 2018，pp. 7444–7452，DOI 10.1609/AAAI.V32I1.12328（ML Anthology）；arXiv 版首页也印着 AAAI 2018 版权行。

**原文摘录**

### 6b. 人脸关键点 + GCN 的代表作：DAG（Li et al., ECCV 2020）

- 论文 *Structured Landmark Detection via Topology-Adapting Deep Graph Learning*，模型叫 Deep Adaptive Graph（DAG）。把关键点建成图，用两级级联 GCN 回归关键点坐标；在三个人脸数据集上测试：WFLW（98 点）、300W（68 点）、COFW-68，另有三个 X 光医学数据集。

## 7. GCN 公式里的邻接矩阵；先学相似度矩阵再当邻接矩阵用

**结论：成立。可信度：高。**

### 7a. GCN（Kipf & Welling, ICLR 2017）原文公式

式 (2)：

H^(l+1) = σ( D̃^(-1/2) Ã D̃^(-1/2) H^(l) W^(l) )，其中 Ã = A + I_N，D̃_ii = Σ_j Ã_ij

LaTeX：`H^{(l+1)} = \sigma\left(\tilde{D}^{-\frac12}\tilde{A}\tilde{D}^{-\frac12}H^{(l)}W^{(l)}\right),\ \tilde{A}=A+I_N,\ \tilde{D}_{ii}=\sum_j \tilde{A}_{ij}`

**原文摘录**

> "We consider a multi-layer Graph Convolutional Network (GCN) with the following layer-wise propagation rule: H(l+1) = σ(D̃^-1/2 Ã D̃^-1/2 H(l) W(l)). (2) Here, Ã = A + I_N is the adjacency matrix of the undirected graph G with added self-connections. I_N is the identity matrix, D̃_ii = Σ_j Ã_ij and W(l) is a layer-specific trainable weight matrix."（第 2 节；页眉 "Published as a conference paper at ICLR 2017"；页面渲染 `pdf\gcn_p-02.png`）

- 论文把这一步叫 "renormalization trick"（2.2 节）。

**链接**：https://arxiv.org/pdf/1609.02907

### 7b. "先学一个相似度矩阵 S，再当邻接矩阵用"（graph structure learning）

代表性出处，按"和本课的关系"从近到远：

1. **2s-AGCN（Shi et al., CVPR 2019）**——也是骨架动作识别，正好接在 ST-GCN 后面讲。每层的邻接矩阵 = A_k（人体天然骨架）+ B_k（整张矩阵都可学）+ C_k（每个样本单独算的**相似度矩阵**）。C_k 用嵌入后的点积 + softmax 算出 N×N 的顶点相似度，当作"软边"。

> "The main difference lies in the adjacency matrix of the graph, which is divided into three parts: Ak, Bk and Ck."

> "The third part (Ck) is a data-dependent graph which learn a unique graph for each sample. To determine whether there is a connection between two vertexes and how strong the connection is, we apply the normalized embedded Gaussian function to calculate the similarity of the two vertexes"

> "They are then multiplied to obtain an N × N similarity matrix Ck, whose element Ckij represents the similarity of vertex vi and vertex vj. The value of the matrix is normalized to 0 - 1, which is used as the soft edge of the two vertexes."

链接：https://arxiv.org/pdf/1805.07694 ；发表信息（CVPR 2019，DOI 10.1109/CVPR.2019.01230）：https://mlanthology.org/cvpr/2019/shi2019cvpr-twostream/

2. **IDGL（Chen, Wu, Zaki, NeurIPS 2020）**——通用 GNN 的典型做法：先用可学习的加权余弦相似度算出相似度矩阵 S，再稀疏化，变成邻接矩阵 A 给 GNN 用。

> "we cast the graph structure learning problem as similarity metric learning, which will be jointly trained with the prediction model dedicated to a downstream task."

> "We hence proceed to extract a symmetric sparse non-negative adjacency matrix A from S by considering only the ε-neighborhood"

链接：https://arxiv.org/pdf/2006.13009 （首页脚注 "34th Conference on Neural Information Processing Systems (NeurIPS 2020)"）

3. **综述**：Zhu et al., *A Survey on Graph Structure Learning: Progress and Opportunities*（arXiv 2103.03036；正式发表在哪本期刊 / 会议没核实）把这类方法归为 "metric-based approaches"：

> "Metric-based approaches use kernel functions to compute the similarity between node feature/embedding pairs as the edge weights."

链接：https://arxiv.org/pdf/2103.03036

**课上建议说法**

> "图神经网络最核心的公式里就有我们学的邻接矩阵：先给 A 加上单位矩阵（每个点也连自己），再按每个点的'度'做归一化。更进一步，有的网络连邻接矩阵都不用人给：它先算出'哪两个点更像'的相似度矩阵，再把它当邻接矩阵用。"
