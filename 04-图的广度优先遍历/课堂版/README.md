|---|---|

## 对讲法的调整和理由（我定的默认做法）

1. **先水波后图**：用"石子落水一圈圈推出去"把"层层扩散"讲直观，第 1 段最后一步再把同心圆摆回教材的图，说"第几圈 = 第几层"。（对应 DFS 课堂版的"先迷宫后图"。）
2. **层号从 0 起**：起点 v1 是第 0 层，这样"层号 = 离起点的最短边数"不用减一。B 站视频工程也是从 0 起（`LAYER_OF`）。
3. **标记时机按教材算法 7.6：入队时就置 TRUE 并访问**，所以图上"在队里"的顶点已经插旗、已经进序列；"出队"只是把它拿出来扫邻接点。第 4 段专门用"出队才标记会重复入队"的反例讲为什么。
4. **第 3 段每出队一个顶点拆成"出队"和"看邻接点"两步**（和 DFS 课堂版"走到"和"往哪走？"对应），另外加了两个提问步："下一个出队？"（只在第一次问，讲先进先出）和"队里是第几层？/ 正好第 2 层"（队里正好是最大的一层 v4 v5 v6 v7 时问，讲队列和层的关系）。最后加一步"按层排好"。
5. **第 5 段"先挑大的"后加一步弧线**，讲同层顶点的先后由上一层的先后决定（v3 先出队，它带进来的 v7 v6 就排在 v5 v4 前面）。"从 v1 出发共 8 种"是 Python 用 7! 个排列逐个检查数出来的。
6. **第 6 段用"把生成树提起来"讲层号 = 最短边数**，并和 DFS 树并排（DFS 树用紫色、BFS 树用橙色，和两份页面的主色区分开）。
7. **第 7 段代码按教材算法 7.6**，只去掉了 `Status (*Visit)(int v)` 这个函数指针参数；第三版为了 48px 字号放得下，把 `visited[v] = TRUE; Visit(v); EnQueue(Q, v);` 和内层同样的一句各拆成两行（`EnQueue` 单独一行），三条标注一条一条出。
8. **小练默认起点 v6**（和 DFS 课堂版同一个起点，方便对比）：v7 就在 v6 旁边、排第 3，v8 却要 5 条边，最远第 5 层。第二问问"最远第几层"而不是"队列最长时几个"，因为它直接练"层号 = 最短边数"。
9. **小结做成 DFS / BFS 两栏对照**（DFS 橙、BFS 蓝），两节连着上，最后一页正好把两种遍历放在一起。
10. **第 4 段反例隐藏访问序列**（第三版）：理由见"第三版改动"第 4 条。
