# KMP：失配了，i 凭什么不回头？（next 与 nextval）（脚本 / 分镜，阶段 A 已审定；阶段 B 制作中）

## 定位

- **一句话**：开头先让"小 i"在朴素匹配里被一把拽回去（小戏剧），问"能不能一步都不退"；然后在同一个失配现场看出"已匹配那段头尾相同 → 模式可以直接滑过去"，由此定义 next，逐位手推 next，拿 next 把匹配走完；再用"同一个坑摔两次"引出 nextval 并手推；最后留一道小题。
- **观众**：大一新生（刚学串），考研党（手推 next / nextval 是必考）。
- **记号严格按严蔚敏《数据结构（C 语言版）》4.3**：串下标从 1 起；主串 S、模式 T，指针 i、j；next[1] = 0；next[j] = max{k | 1 < k < j 且 'p₁…p_{k−1}' = 'p_{j−k+1}…p_{j−1}'}，集合空时为 1；nextval：p_j = p_{next[j]} 时 nextval[j] = nextval[next[j]]，否则 = next[j]。教材例子：模式 `abaabcac`，主串 `acabaabaabcacaabc`。
- **顺序（没有老师课堂资料，按教材主线）**：朴素回溯的痛 → i 不退、模式滑过去 → 定义 next → 手推 next → 用 next 匹配 → nextval 的动机 → 手推 nextval → 小题。
- **目标时长**：speed 1.1 估计约 2:26（加上动画停顿约 2:30，见文末）；超出"2 分钟左右"，砍法见"拿不准"第 1 条。
- **风格（用户 2026-10-29 补充的硬要求）**：
  - **轻松有趣、引人入胜**。开头 10 秒内必须有钩子：本片用"朴素匹配被坑"的小戏剧——小 i 一路比到第 8 位，失配后被一把拽回第 4 位（第 1 镜，约 5～11 秒）。
  - **一个贯穿全片的拟人角色："小 i"**：主串上方一个珊瑚橙的小箭头，带两只圆点眼睛，只想往前走。朴素匹配时它被拽回去（委屈脸）；KMP 里它站着不动，让模式串自己滑过来（得意脸）；全片所有"滑动"都是"小 i 不动、模式串滑到它面前"。比喻只管直觉，定义、公式、数字一律按教材，不拿比喻替代定义。
  - **旁白口语、短句**，两处轻松小幽默："凭什么重来？"（第 1 镜）、"同一个坑里又摔一次"（第 6 镜）。不玩梗、不喊口号。
  - **音乐**：BGM 用模板 numpy 合成的 `bright-01`（C 大调 108 BPM）+ 旁白闪避（`bgm.ts`）；关键节点配音效（只用模板已有的 7 个：`tick`、`whoosh`、`pop`、`ding`、`ding_hi`、`stamp`、`snap`）。每镜的 BGM 起落写在该镜"音乐"一行，汇总见"BGM 提示表"。
  - **字幕中英双语**：每条旁白都有 English 列。
  - **解说用 TTS**：MiniMax `speech-2.8-hd`，`aigc_watermark=false`，speed 1.1。`speak` 列是给 TTS 的读法版：字母串拆开念（"a b a a b"），数组念成"零一一二……"，下标念成"第 j 位"，不出现符号。
  - 浅色方格纸（`PaperKit`），珊瑚橙只给当前焦点；画面先行，先具体后抽象，每镜一个视觉焦点。

### 第 4 镜 · 手推 next（实测 0:52–1:19，考研重点，放慢）

画面（手推布局，照抄脚本第 2 节）：
- 主串淡出（whoosh），模式串放大上移到中间，next 一排空格在下面，第 1、2 格写着 0、1 已就位（s4a，各一个 pop）。小 i 退到左上角当观众，托腮看。

  - j = 4：看 aba，a = a → 2。
  - j = 5：看 abaa，最长还是 a → 2（先试 ab 对 aa ✗，再缩到 a ✓，演示"从长往短试"）。

  - j = 8：看 abaabca，a = a → 2。

## 数字核对（`scripts/check_numbers.py`，全部 OK）

做法：next / nextval 先**按定义暴力枚举 k、逐字比较前后缀**，再用教材递推算法（get_next / get_nextval）各算一遍互相核对；匹配过程真的一步步模拟（教材 Index / Index_KMP），每次字符比较都打印 i、j。

- 模式 `abaabcac`（j = 1..8）：
  - **next = 0 1 1 2 2 3 1 2**（暴力 = 递推 = 教材）。
  - **nextval = 0 1 0 2 1 3 0 2**（暴力 = 递推 = 由 next 手推法）。⚠ 任务说明里给的 `0 1 0 2 1 3 0 1` 末位是错的：j = 8 时 p₈ = c，next[8] = 2，p₂ = b，不相等 → 照抄 next[8] = 2。本片以脚本为准。
  - 手推 next 逐位：j = 2 看 a → 无 → 1；j = 3 看 ab → 无 → 1；j = 4 看 aba → a → 2；j = 5 看 abaa → a → 2；j = 6 看 abaab → ab → 3；j = 7 看 abaabc → 无 → 1；j = 8 看 abaabca → a → 2。
  - 手推 nextval 逐位："相同"的只有 j = 3（p₃ a = p₁ a → 抄 nextval[1] = 0）、j = 5（p₅ b = p₂ b → 抄 nextval[2] = 1）、j = 7（p₇ a = p₁ a → 抄 0）；其余照抄 next。
- 穷举：字母表 {a, b, c}、长度 1～9 的全部 29523 个模式串，next 暴力 vs 递推、nextval 暴力 vs 递推 vs 手推法，**0 处不一致**；主串 {a, b} 长 ≤ 10 × 模式长 ≤ 4 共 61380 组，朴素 / KMP(next) / KMP(nextval) 找到的位置与 `str.find` **0 处不一致**。
- 朴素匹配（主串 `acabaabaabcacaabc`，n = 17）：共 **20 次**比较，找到位置 **6**。各趟（模式头位置:比较次数）= 1:2、2:1、3:6、4:1、5:2、6:8。第 1 镜用第三趟：模式头对 s3，前 5 个相等，失配在 **i = 8, j = 6**（s₈ = a vs p₆ = c），朴素随后 i = i − j + 2 = **4**、j = 1。
- KMP（用 next）：共 **15 次**比较，位置 **6**，i 从不后退。失配点：#2 i = 2, j = 2 → j = next[2] = 1；#3 i = 2, j = 1 → j = 0 → i = 3, j = 1；#9 i = 8, j = 6 → j = next[6] = 3（模式头从 s3 滑到 s6，滑 3 格）；#10～#15 一路相等到 i = 13, j = 8。同一主串上用 nextval 也是 15 次（这条主串上省不了，所以第 6 镜换主串）。
- 第 6 镜主串 `abaaabaabcac`（自造）：用 next 共 14 次（#5 i = 5, j = 5 失配 → j = 2；#6 i = 5, j = 2 s₅ a vs p₂ b 又失配 → j = 1；#7 相等），用 nextval 共 13 次（#5 失配 → j = nextval[5] = 1 直接相等），**少比 1 次**；位置都是 5。
- 小题 `ababaa`：**next = 0 1 1 2 3 4**（j = 4 看 aba → a；j = 5 看 abab → ab；j = 6 看 ababa → aba），nextval = 0 1 0 1 0 4。
