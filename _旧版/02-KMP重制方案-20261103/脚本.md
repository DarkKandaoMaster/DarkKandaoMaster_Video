# KMP：失配以后，尺子该挪几格（next与nextval）· 新版分镜+旁白（待用户过目）

## 定位

- **一句话**：全片只用一个动作讲KMP：失配时把模式的“复印件”对着模式自己往右滑，第一次头尾对上的地方就是下一次该对齐的地方。先在朴素匹配里看见白比，再讲清“主串那段已经知道，就是模式的前缀，所以挪几格只看模式自己，能提前算成表”，同一个动作手推next，拿next在教材主串上跑一遍，最后用教材`aaaab`引出nextval并手推。
- **观众**：刚学串的大一学生；考研党照着能推题。
- **记号**：严蔚敏《数据结构（C语言版）》4.3。下标从1起；next[1]=0；next[j]=p1…p(j−1)的最长相等真前后缀长度+1（没有时为1）；nextval：p_j=p_next[j]时nextval[j]=nextval[next[j]]，否则nextval[j]=next[j]。例子：模式`abaabcac`、主串`acabaabaabcacaabc`；nextval动机用教材的模式`aaaab`、主串`aaabaaaab`；小题`ababaa`。
- **时长**：speed 1.1约3:15，speed 1.0约3:32（`scripts\check_script.py`实测，见文末）。
- **风格**：深色黑板+尺子；旁白口语档（短句、像老师站在黑板前讲）；中英双语字幕；BGM `calm-01`。

## 和旧版的区别

旧版2:28塞了8个镜头，语速1.1，核心那句“失配时主串那段就是模式的前缀，所以挪多远只看模式自己”只给了10秒，手推占了50秒，观众会抄步骤、不懂为什么。新版把这个道理单独做成第2镜（speed 1.1约40秒，全片最慢，带三处定格），并补上旧版没讲的一步：挪1格、2格在已知的格子上就会出错，挪3格是第一个可能对上的位置，所以跳过去漏不掉答案。“复印件对着自己右滑”这一个动作从第2镜贯穿到手推next和小题，手推每一位都是同一套画面，观众只学一个动作。拟人角色“小i”、表情、角落Chip、公式卡全部去掉，指针就是一根粉笔箭头；公式只在第3镜出现一次。nextval的动机换成教材的`aaaab`：b和a连比4次，比旧版自造主串“白比1次”直观，也和考研书一致。画面从浅色方格纸换成深色黑板，BGM从bright-01换成更安静的calm-01，和《对称矩阵压缩存储》拉开。

## 画面约定（1920×1080，对齐`风格小样`里的两张静帧和`说明.md`）

**只用这几种元素**：轨道、尺子、复印件、勾/叉（含“白比”黄圈）、括号、便签、粉笔箭头。不出现角色、表情、Chip、卡片。黑板上的粉笔字只有：箭头上的i、括号旁的“前缀/后缀”、第3镜那一行公式、第5镜和第6镜右上角的比较次数。

**颜色**：深墨绿黑板（带一点粉笔灰质感、擦痕）；文字粉笔白；焦点粉笔黄；正确粉笔绿、错误粉笔红（都偏柔和）；辅助粉笔青。前缀括号用粉笔青，后缀括号用粉笔黄。

**颜色值、字号**：照`风格小样\说明.md`的色值表和字号表（`src\board\theme.ts`），黑板四周一圈20px木框。

**字体**：中文NotoSansSC；字符和数组Consolas；便签上的手写数字用Ink Free（本地字体，小样已用）。

**匹配布局**（第1、2、5、6镜）：
- 粉笔箭头i：轨道上方y 170–290，上面写一个“i”，箭头尖指着当前格；往右走时身后拖一道粉笔线。
- 轨道（主串）：17格，格宽84、步长96，x 150–1770，y 330–414；下标1–17写在格子上方（y 307，粉笔灰小字）；左边一个“S”。
- 尺子（模式）：半透明粉笔黄长条，左端一个带圆孔的把手（写j），8格，和轨道逐格上下对齐，y 490–625；格子下沿写j。尺子头对着主串第h位时，第j格的x=150+(h+j−2)×96。
- 勾/叉：轨道和尺子之间的缝里（y 420–485），一根短竖线加勾或叉。
- 便签next：右下角米白便签，x 1290–1800，y 670–860，左倾约2°；标题“next”，8格，格上小号j，格里手写数字；当前格黄框。

**手推布局**（第2镜s2c–s2e、第3、4、7镜）：轨道调暗到20%，移到顶部y 80–165；尺子放大到格宽108、步长124，x 420起，y 425–600；复印件（虚线、几乎透明的尺子）在尺子上方y 220–390，从左端对齐开始往右滑，每挪一格0.35秒；勾/叉画在两排之间的缝里。当前在推的第j位：p1…p(j−1)亮，p_j虚线框，后面几格调暗。全对上时，重合的格子在复印件和尺子上都填粉笔黄；尺子下方画两个括号：粉笔青括号在开头（标“前缀ab”），粉笔黄括号在结尾（标“后缀ab”），中间一个“=”。复印件往右最多挪6格，j=7、8时右端会到x 1900–2030，推这两位前尺子整体先左移2格让出位置。

**字幕**：底部居中y 950–1030，直接写在黑板上、不加底卡；中文38px粉笔白，英文24px偏灰；每屏≤18个汉字，一句说一件事。表格里字幕列的“ / ”是分屏切点。

**转场**：黑板擦横扫一下（whoosh），没有别的花样。

## 数字核对（`scripts\check_numbers.py`，全部OK）

做法：next、nextval先按定义暴力枚举，再用教材递推算法（get_next / get_nextval）各算一遍，再用画面里的两种手推法（复印件右滑法、由next手推nextval）各算一遍，互相比对；匹配过程按教材Index / Index_KMP一步步模拟，每次比较都打印i、j。

- 模式`abaabcac`：**next = 0 1 1 2 2 3 1 2**，**nextval = 0 1 0 2 1 3 0 2**（暴力 = 递推 = 手推）。nextval里字母相同的只有j=3、5、7（p3=p1=a抄0，p5=p2=b抄1，p7=p1=a抄0）；j=8是c对p2=b，不同，照抄2。
- 复印件右滑（第2、4镜照抄，✓×是复印件和原件逐格比）：
  - j=4 `aba`：挪1格 ××；挪2格 ✓ → 重合1格 → 2
  - j=5 `abaa`：挪1格 ××✓；挪2格 ✓×；挪3格 ✓ → 2
  - j=6 `abaab`：挪1格 ××✓×；挪2格 ✓××；挪3格 ✓✓ → 重合`ab` → 3
  - j=7 `abaabc`：挪1–5格都有叉（最右一格都是×），挪6格滑出去 → 1
  - j=8 `abaabca`：挪1–5格都有叉，挪6格 ✓ → 2
  - j=2、3：重合0格 → 1
- 穷举：字母表{a,b,c}、长度1–9的全部29523个模式串，next暴力/递推/复印件右滑法、nextval暴力/递推/手推法，**0处不一致**；主串{a,b}长≤10 × 模式长≤4共61380组，朴素、KMP(next)、KMP(nextval)找到的位置和`str.find`**0处不一致**。
- 朴素匹配（主串`acabaabaabcacaabc`）：共**20次**，位置**6**。各趟（尺子头: 比较次数）= 1:2、2:1、3:6、4:1、5:2、6:8。第三趟尺子头对s3，前5个相等，**i=8、j=6失配**（s8=a对p6=c），朴素随后i退回**4**。退回后在s4–s7上又比了**5次**（头对s4：s4≠p1；头对s5：s5=p1、s6≠p2；头对s6：s6=p1、s7=p2），第15次比较才重新走到s8。
- KMP（next）：共**15次**，位置**6**，i从不后退。失配查表：i=2、j=2 → 1；i=2、j=1 → 0（i、j各加1）；i=8、j=6 → 3（尺子头从s3滑到s6）。朴素的20次去掉那5次白比，剩下的15次和KMP的15次逐次相同（i、j、字符都一样），所以“省下的就是那5个黄圈”成立。
- nextval动机（教材`aaaab`、主串`aaabaaaab`）：next = 0 1 2 3 4，nextval = 0 0 0 0 4。用next：#4 i=4、j=4失配后，j依次换3、2、1，s4（b）一共和a比了**4次**，再j=0前进；全程**12次**。用nextval：#4失配后nextval[4]=0，一步前进；全程**9次**，少3次。位置都是5。朴素15次。
- 小题`ababaa`：**next = 0 1 1 2 3 4**（j=4重合`a`，j=5重合`ab`，j=6重合`aba`，都是挪2格第一次全对上），nextval = 0 1 0 1 0 4。
