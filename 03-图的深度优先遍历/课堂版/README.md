- 网址后面加 `?mode=2d`（例如把文件拖进浏览器后在地址栏末尾补上）= 强制 2D，按 D 也不会切到 3D。

- 浏览器右键菜单已屏蔽（右键 = 上一步）。弹出的提示是画面中间偏下的一行 44px 字，两三秒自己消失，不是常驻提示条。

### 5 邻接表（8 步，2D）

左边是缩小的图，中间是教材式邻接表（顶点表 + 边链表，下标从 0 起，`∧` 表示空指针），右边是访问序列（① 先挑小的、② 先挑大的、③ 按邻接表走，只写圈号）。

| 步 | 画面 | 老师可以说的 |

| 1 | "给定邻接表"，只出顶点表 | "考试怎么考？题目会给定存储结构。" |
| 2 | "链里存下标"，每个顶点挂上一条链 | "每个顶点挂一条链，链里存的是下标，从 0 起：下标 1 就是 v2；链本来是从小到大排的。每个结点两格：adjvex（邻接点下标）和 nextarc（下一个）。" |

## 3D 用在哪

数字和文字全部在平面的 HUD 层（2D 画布），3D 层只画东西不画字（顶点名字也是 HUD 按 3D 坐标投影后画的，所以和 2D 模式一样清楚，字号也一样）。

1. **第 1 段迷宫（6 步）**：立体的墙挡住视线，小人只能看到眼前的岔路，对应 DFS"只看当前顶点的邻接点"；插旗 = visited；红栅栏 = 撞南墙。最后一步墙降下去、压平成棋盘上的图。
2. **第 2–4 段棋盘（31 步）**：G4 放在一块斜放的立体棋盘上，顶点是有高度的圆台（颜色跟着状态变：没来过白、在栈里深橙、出栈浅橙），旗子 = visited，小人 = 当前顶点，走 / 退都是小人沿走廊移动，撞南墙时走廊口立红栅栏、当前顶点外有一圈红色脉冲，"往哪走？"时走廊口冒问号。右下角递归栈是立体积木，进栈从上面落下、出栈往上飘走淡出（和 2D 模式在同一位置，2D 画平面方块）。第 4 段先挑大的那遍插蓝旗。
3. **第 6 段非连通图（7 步）**：G6 三块分别是三座小岛，直观看出"走不过去"，每次再调 DFS 换一种颜色的旗。
4. **第 9 段第 2、3 步"把生成树提起来"**：把 v1 往上一提，树按深度一层层垂下来，"深度"变成看得见的高度，对上右下"栈最深时"的那根栈。

2D 兜底：同样的步数和字；第 1 段画成俯视平面迷宫，第 2–4、6 段画平面图（顶点、旗子换成颜色、问号、红栅栏、当前框都有），第 9 段画成侧视的分层树。两种模式每一步的字和状态由 verify.py 逐步比过，完全相同；字号由 font_check.py 两种模式都量过。

性能：本机（RTX 4060 笔记本）3D 满帧。3D 只在上面这些步骤里渲染，其他步骤 WebGL 画布隐藏、不耗显卡。

## 对讲法的调整和理由

1. **先迷宫后图**：用迷宫把口诀和"插旗 / 原路退回"两个动作讲直观，第 2 段再把这两个动作对应成 visited 数组和栈，第 3 段才在图上走。
2. **第 3 段"到达"和"往哪走？"分开**：先看小人走到哪、栈怎么变，再停下来问下一步去哪；连续退栈（v5 → v8 → v4 → v2 → v1）故意不合并，让学生看到"退的时候不访问"。
3. **最后一次退栈写"出栈"**（不是"再退"），因为栈里只剩 v1 了，再退就是栈空、遍历结束。
4. **第 4 段先挑编号大的再走一遍**，用两条都对的序列引出"不唯一"，并给出"从 v1 出发一共 8 种"（Python 把所有挑法逐个模拟数出来的）。
5. **第 5 段用教材式邻接表**（adjvex 下标从 0 起，v1 对应 0），讲清考题为什么有唯一答案；链倒过来正好变成第 ② 条，和第 4 段呼应。
6. **第 6 段非连通图**用 B 站视频那张 G6，引出 DFSTraverse 外层循环和"调用次数 = 连通分量个数"。
7. **第 7 段代码按教材算法 7.4、7.5**，只去掉了 `Status (*Visit)(int v)` 这个函数指针参数（课堂上不讲函数指针），三条标注一条一条出，把代码和前面讲的三件事连起来。
8. **小练默认起点 v6**：v7 就在 v6 旁边却最后一个，栈最深 7 层，能看出 DFS"深"的特点；也可以现场点顶点换题。
9. **结尾加生成树和"提起来"**：把"深度"和"栈深"连起来，也给 BFS 课堂版第 6 段"DFS 5 层，BFS 4 层"的对比留了铺垫。
10. **第三版**：访问序列行前只写圈号、递归栈的"栈顶"换成小三角、第 4 段后两步收起空栈、小结合并成 3 步——都是为了字放大以后不挤，删掉的话都在上面"老师可以说的"里。
