# 图的深度优先遍历：课堂版

2026-11-16 做，同日改出第二版。任课老师 2026-11-24 上课用，**只做正课**（DFS 算法本身）。内容来自同目录的 B 站视频工程（`..\`，图、序列、邻接表、非连通图都是同一份数据，没有改动视频工程的任何文件）。

老师自己讲，页面不配音。全部手动、一按一步，没有自动播放。单文件、完全离线（不联网、不用 CDN 和网络字体，build 时检查过里面没有任何网址），1920×1080 设计，任意窗口等比缩放。**画面底部没有按键提示条**，也没有按钮，按键只写在这份 README 里；右下角只有一行很淡的 20px 小字"段 · 本段第几步"（如 `3 · 5/24`），给老师自己看进度。

## 第二版改动（2026-11-16，按用户看第一版后的意见）

1. **字少了**：每步只留一个标题（≤ 13 个字）和最多一行说明；原来屏幕上的解释、括号补充、重复说法都挪到下面各段的"老师可以说的"里。每步屏幕上的字平均 **42.9 → 13.9 个**（最多一步 124 → 92 个，是最后的小结；只算标题和说明句子，不算面板、表格、代码、顶点名字，verify.py 统计）。

4. 其余不变：没有底部提示条、字号下限、离线单文件、核对和交互测试、逐张看截图、备份录屏重录。

## 九段、69 步：画面 + 老师可以说的（提示，不是台词）

"互动点"是建议停下来问学生的地方。屏幕上的字就是"画面"一列引号里的那些，其余解释都在"老师可以说的"里。

第 2–4 段右边三块面板：`visited` 数组（T / F）、访问序列（一个个橙色小方块）、递归栈（竖着放，栈顶在上，旁边箭头"栈顶 →"；3D 模式下是立体积木）。图上**在栈里**的顶点是深橙色、栈里的路径是深橙粗线，**已经出栈**的顶点变浅橙，当前顶点外面多一圈黑框，撞南墙时是红框。3D 棋盘上：每个顶点是一个圆台，插了旗 = visited 为 T；小人站在当前顶点上；撞南墙时两条走廊口立起红栅栏。

老师可以说：
- 每个"往哪走？"都是**互动点**：可以让学生先说再按（前几步问，后面熟了就直接按）。说法："visited[vX] 置 T，vX 进栈；看它的邻接点，来过的跳过，没来过的按编号从小到大挑第一个。"
- 第 10、20 步"撞南墙！怎么办？"：**问学生**"该退到哪？"——答案就是栈顶下面那个。

## 3D 用在哪

数字和文字全部在平面的 HUD 层（2D 画布），3D 层只画东西不画字（顶点名字也是 HUD 按 3D 坐标投影后画的，所以和 2D 模式一样清楚）。

1. **第 1 段迷宫（6 步）**：立体的墙挡住视线，小人只能看到眼前的岔路，对应 DFS"只看当前顶点的邻接点"；插旗 = visited；红栅栏 = 撞南墙。最后一步墙降下去、压平成棋盘上的图。
2. **第 2–4 段棋盘（31 步）**：G4 放在一块斜放的立体棋盘上，顶点是有高度的圆台（颜色跟着状态变：没来过白、在栈里深橙、出栈浅橙），旗子 = visited，小人 = 当前顶点，走 / 退都是小人沿走廊移动，撞南墙时走廊口立红栅栏、当前顶点外有一圈红色脉冲，"往哪走？"时走廊口冒问号。右边递归栈是立体积木，进栈从上面落下、出栈往上飘走淡出（栈和 2D 模式在同一位置，2D 画平面方块）。第 4 段先挑大的那遍插蓝旗。
3. **第 6 段非连通图（7 步）**：G6 三块分别是三座小岛，直观看出"走不过去"，每次再调 DFS 换一种颜色的旗。
4. **第 9 段第 2、3 步"把生成树提起来"**：把 v1 往上一提，树按深度一层层垂下来，"深度"变成看得见的高度，对上右边"栈最深时"的那根栈。

2D 兜底：同样的步数和字；第 1 段画成俯视平面迷宫，第 2–4、6 段画平面图（顶点、旗子换成颜色、问号、红栅栏、当前框都有），第 9 段画成侧视的分层树。两种模式每一步的字和状态由 verify.py 逐步比过，完全相同。

性能：本机（RTX 4060 笔记本）3D 满帧。3D 只在上面这些步骤里渲染，其他步骤 WebGL 画布隐藏、不耗显卡。

## 对讲法的调整和理由

1. **先迷宫后图**：用迷宫把口诀和"插旗 / 原路退回"两个动作讲直观，第 2 段再把这两个动作对应成 visited 数组和栈，第 3 段才在图上走。
2. **第 3 段"到达"和"往哪走？"分开**：先看小人走到哪、栈怎么变，再停下来问下一步去哪；连续退栈（v5 → v8 → v4 → v2 → v1）故意不合并，让学生看到"退的时候不访问"。
3. **最后一次退栈写"出栈"**（不是"继续退"），因为栈里只剩 v1 了，再退就是栈空、遍历结束。
4. **第 4 段先挑编号大的再走一遍**，用两条都对的序列引出"不唯一"，并给出"从 v1 出发一共 8 种"（Python 把所有挑法逐个模拟数出来的）。
5. **第 5 段用教材式邻接表**（adjvex 下标从 0 起，v1 对应 0），讲清考题为什么有唯一答案；链倒过来正好变成第 ② 条，和第 4 段呼应。
6. **第 6 段非连通图**用 B 站视频那张 G6，引出 DFSTraverse 外层循环和"调用次数 = 连通分量个数"。
7. **第 7 段代码按教材算法 7.4、7.5**，只去掉了 `Status (*Visit)(int v)` 这个函数指针参数（课堂上不讲函数指针），三条标注一条一条出，把代码和前面讲的三件事连起来。
8. **小练默认起点 v6**：v7 就在 v6 旁边却最后一个，栈最深 7 层，能看出 DFS"深"的特点；也可以现场点顶点换题。
9. **结尾加生成树和"提起来"**：把"深度"和"栈深"连起来，顺便给下节课 BFS 的生成树对比留个铺垫。

## 已知限制 / 需要老师或用户定的
