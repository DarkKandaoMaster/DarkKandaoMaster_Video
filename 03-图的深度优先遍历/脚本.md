# 图的深度优先遍历（DFS）· 分镜 + 旁白

> 本次用户无人值守、全程授权，脚本写完未等过目直接制作。下面“自己定的默认”一节列出了需要用户事后确认的选择。

## 定位

- **一句话**：口诀“不撞南墙不回头”开场，在教材图G4上一步步走DFS，同步画visited数组和递归栈；回退＝小指针沿来的边退回＋栈顶弹出，让人看出“栈顶就是你站的位置”。然后换一种挑法再跑一遍看出序列不唯一，给定邻接表后序列唯一（考研考点），非连通图调几次DFS＝几个连通分量，复杂度一句带过，最后一道8秒限时题。
- **观众**：刚学图的大学生＋考研党。
- **记号**：严蔚敏《数据结构（C语言版）》第7章。顶点v1…v8；邻接表顶点表下标从0起、边结点adjvex存下标（教材画法），visited取TRUE/FALSE（画面写T/F）。
- **例图**：教材图7.13的无向图G4，边v1-v2, v1-v3, v2-v4, v2-v5, v3-v6, v3-v7, v4-v8, v5-v8, v6-v7。
- **时长**：speed 1.1估约3:00（`scripts\check_script.py`）。
- **风格**：图论系列新视觉（见下），旁白口语档，中英双语字幕，BGM bright-01。

## 画面约定（1920×1080）

**系列视觉“图论·暖白”**（`src\graph\theme.ts`）：
- 底色暖白`#FAF7F0`，铺一层很淡的点阵（间距36px、点径2.4px、墨色6%透明度），四角极轻的暖灰暗角。不用方格纸，不用深色。
- 顶点：白底圆（半径40），墨色描边3.5px，中间写斜体v加下标数字（Cambria Italic + Noto Sans）。
- 边：暖灰`#CFC8BA`，6px，圆头。
- 每一遍遍历一种颜色：第1遍橙`#E8590C`，第2遍蓝`#1C7ED6`，第3遍（邻接表）绿`#2B8A3E`；非连通图三次调用依次橙、蓝、绿。
- 顶点状态：未访问＝白；在栈里＝实心彩色、白字；已出栈＝浅色底＋彩色描边＋彩色字。边同理：在栈路径上＝实色粗线；退回后＝同色浅线（剩下就是DFS生成树）。
- 访问顺序：顶点右上角一个小圆牌写第几个访问；右侧“访问序列”一行彩色药丸，多遍时一行一行往下排，颜色和那一遍一致。
- 指针：墨色圆环套在当前顶点上；沿边移动时缩成一个小圆点（走过去、退回来都是它），不写“回退”二字。
- 查看已访问邻接点：从当前顶点沿那条边伸出一截虚线再缩回，visited里对应格子闪一下。
- 撞南墙：当前顶点外圈红色脉冲一次，栈顶格同时描红。
- 文字：中文Noto Sans SC；代码、下标、T/F用Consolas；变量斜体用Cambria Italic。全部本地字体。

- 音效（模板的7个）：pop（顶点点亮、入栈）、tick（画边、探邻居、倒计时）、whoosh（转场、退回）、snap（出栈）、stamp（口诀、撞南墙）、ding（遍历结束、答对位置）、ding_hi（揭晓答案）。

## 数字核对（`scripts\check_numbers.py`，全部OK）

- 先挑编号小的（＝按邻接表）：**v1 v2 v4 v8 v5 v3 v6 v7**（＝教材）；先挑编号大的：**v1 v3 v7 v6 v2 v5 v8 v4**。
- 第一次撞南墙在v5，此时栈为v1 v2 v4 v8 v5；v5的邻接点v2、v8都已访问。第一段回退v5→v8→v4→v2→v1，其间退回v2时看了一次v5（已访问）。栈最深5层（两种挑法都是）。
- 从v1出发的DFS序列共**8种**（递归枚举，与7!=5040个全排列逐个模拟的结果完全相同）。
- 邻接表：0:1→2；1:0→3→4；2:0→5→6；3:1→7；4:1→7；5:2→6；6:2→5；7:3→4；边结点18个＝2e。按E4顺序头插建表得到的表正好是全部倒序，DFS＝第二条序列。
- 非连通图G6（边v1-v2, v1-v3, v2-v3, v4-v5，v6孤立）：DFSTraverse调用3次，分别访问v1 v2 v3 / v4 v5 / v6；并查集数出3个连通分量。
- 复杂度小字：G4 n=8、e=9；矩阵扫8×8=64格；邻接表扫8+18=26个结点。
- 限时题：A、B、D合法，**C不合法**（到v4时栈顶v4的未访问邻接点只有v8，v5不是v4的邻接点）。两种算法判断一致。
